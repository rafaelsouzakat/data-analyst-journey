3) Crie uma conexão com um banco de dados SQLite.

# Conectar ao banco de dados SQLite
conn = sqlite3.connect('escola.db')
cursor = conn.cursor()

4) Criação de Tabelas
Vamos começar criando duas tabelas: alunos e cursos.

# Criar tabela 'alunos'
cursor.execute('''
CREATE TABLE alunos (
    id INTEGER PRIMARY KEY,
    nome TEXT,
    idade INTEGER,
    cidade TEXT
)
''')

# Criar tabela 'cursos'
cursor.execute('''
CREATE TABLE cursos (
    id INTEGER PRIMARY KEY,
    nome TEXT,
    duracao INTEGER  -- duração em meses
)
''')

# Confirmar as mudanças
conn.commit()


5) Inserindo Dados
